FastMultiversion

Build one Minecraft mod for several Minecraft versions and loaders. See GitHub for how to use it.

Gradle plugin

In settings.gradle, the newest release (now 1.1.1):

pluginManagement {
    repositories {
        maven { url = 'https://gahahawang.github.io/FastMultiversion/maven' }
        gradlePluginPortal()
        mavenCentral()
    }
}

plugins {
    id 'cc.gahaha.fastmultiversion' version 'latest.release'
}

Or the dev channel, the newest pre-release or release, whichever is newer (now 1.2.0-dev.1): the repository https://gahahawang.github.io/FastMultiversion/maven-dev with version 'latest.integration'.

IntelliJ IDEA plugin

Install it from a release. It then adds its channel's repository to IntelliJ IDEA, which offers its updates. To add one by hand: Settings → Plugins → ⚙ → Manage Plugin Repositories…, then https://gahahawang.github.io/FastMultiversion/updatePlugins.xml, or https://gahahawang.github.io/FastMultiversion/updatePlugins-dev.xml for the dev channel.
